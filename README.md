# Data Visualization & ETL Lab

Repositório destinado ao versionamento de fluxos de preparação de dados (ETL) e dashboards interativos desenvolvidos ao longo da graduação.

## Visão Geral

O objetivo deste repositório é documentar a construção de pipelines de dados e a criação de visualizações analíticas. O projeto abrange desde o tratamento, limpeza e transformação de bases de dados brutas até a elaboração de painéis operacionais, análises geográficas e apresentações baseadas em storytelling.

## Conteúdo Programático

### ETL e Preparação de Dados (Tableau Prep Builder)
* Limpeza, padronização e tratamento de tipos de dados
* União de arquivos (Unions) e junções relacionais (Joins)
* Agregações, pivotagem de tabelas e criação de campos calculados
* Exportação de bases otimizadas para análise

### Visualização e Análise de Dados (Tableau Desktop / Public)
* Construção de gráficos fundamentais e avançados
* Criação de dashboards interativos com filtros e ações
* Análise de dados geoespaciais e mapas (Geoanálise)
* Construção de histórias para apresentação de insights (Data Storytelling)
* Desenvolvimento de painéis de negócios (ex: Petshop, Cinema, Vendas)
